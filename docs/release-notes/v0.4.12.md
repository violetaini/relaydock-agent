# RelayDock Agent v0.4.12

- 修复在线升级错误地使用 /usr/local/bin/relaydock-agent 的问题：按当前进程的实际可执行文件路径验签并替换，支持自定义安装目录。
- 下载使用独立临时目录，验证通过后在目标目录内创建旁路文件并原子替换，避免跨文件系统移动及并发临时文件冲突。
- 手动升级脚本支持自动识别 /opt/relaydock-agent/bin、PATH 或 RELAYDOCK_AGENT_BIN 指定的路径。
- 保留 Ed25519 签名验证及拒绝降级保护；验签失败时不替换旧程序。
- 新增自定义路径升级与验签拒绝回归测试，并在 Linux 发布任务中执行。

旧版本的在线升级处理程序不会自动获得此修复。若旧版在自定义目录内升级失败，需要先通过 SSH 或本机维护通道，用当前已安装 Agent 验证本次发布的二进制及 .sig，再替换实际服务路径并重启服务。不要关闭签名校验，也不需要重建节点配置。
